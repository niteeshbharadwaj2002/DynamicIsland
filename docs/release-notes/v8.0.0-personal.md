## NotchIQ v8.0.0-personal

A personal, offline Dynamic Island for Android, built on [Smart Island](https://github.com/agupta07505/SmartIsland) **7.6.0** by Animesh Gupta. This is the first release under the NotchIQ name and the first major version of the fork: it keeps everything in Smart Island 7.6.0 and adds a mascot, a rebuilt island UI, a new settings UI and a stricter privacy stance.

### Highlights

- **Renamed to NotchIQ.** New app name everywhere (launcher, home header, About, accessibility service), with the status pill moved below the name so it no longer crowds the title.
- **Buddy, a mascot on the pill.** A small character that reacts to events (charging, low battery, unlock, torch, timers, calls), makes short visits when things are quiet and responds to touch.
- **Rebuilt island UI.** A two-slot alert engine, spring presets, a kinetic glow, size-class pill layouts and an idle dashboard.
- **New settings UI.** Grouped lists, Apple HIG-style typography and switches. The Layout screen is regrouped (Quick presets, Exempt apps, Size and position, Camera cutout, Shadow, Motion physics, Kinetic glow) with no description clutter.
- **Fully offline.** No internet permission, no update checker, no weather.

### What is different from the original Smart Island

| Area | Smart Island 7.6.0 | NotchIQ 8.0.0-personal |
|---|---|---|
| Name and app ID | Smart Island, `com.agupta07505.smartisland` | NotchIQ, `com.niteeshbharadwaj.smartisland.personal` (installs next to the original) |
| Network | Internet, location and calendar permissions for weather and updates | **No internet and no location permission.** Calendar is read locally only |
| Updates | In-app GitHub update checker and download screen | Removed. Updates are manual |
| Weather and wind | Idle widgets | Hidden (needs network) |
| Mascot | None | **Buddy**: reactions, moods, visits, gestures, its own settings screen |
| Alerts | Several cards and pills, picker for sibling cards | **Two-slot alert engine**: one main pill plus one companion bubble, messages from the same app fold into one entry, 7 s and 5 s expiry timers |
| Motion | Upstream animation tuning | **Spring presets** (Standard, Bouncy, Snappy, Critical, Loose) and an optional **kinetic glow** |
| Idle screen | Upstream idle widgets | **Idle dashboard** with search, launcher and quick controls, with upstream's idle widgets shown as tiles |
| Backdrop | Glass look | **Backdrop blur** on Android 12 and newer, behind a setting; glass look on older versions |
| Settings UI | Material cards | **Apple HIG-style** grouped lists, typography and switches |
| Layout screen | Mixed card styles with descriptions | One grouped style, titles only, indexed in settings search |
| Hardening | Upstream defaults | Secure-delete notification history, quoted Shizuku values, no notification titles in logs, receivers not exported, ordered listener queue, release logs stripped |
| CI/CD | Telegram notifications, auto-review, auto-commit cleanup | Lint, unit tests and debug build on every PR and push; tagged releases; optional signing via repo secrets; no Telegram |
| Docs | Roadmap, analysis, Copilot instructions | `Rule_Book.md` (how the island decides what to show), requirement notes per change |

Everything else in Smart Island 7.6.0 is carried over: calls, music, timers and stopwatches, charging, hotspot, navigation and downloads, face, fingerprint and app-lock animations, headphone and USB events, the clock rework, gestures, backup and restore, and the Spanish, Japanese, Portuguese and Chinese translations.

### Changes since 7.6.0-personal

- App renamed to NotchIQ, home header status pill moved below the name ([#6](https://github.com/niteeshbharadwaj2002/NotchIQ/issues/6)).
- Layout screen regrouped and descriptions removed; settings search indexes every Layout group ([#7](https://github.com/niteeshbharadwaj2002/NotchIQ/issues/7)).
- Version bumped to 8.0.0-personal (versionCode 11).

### Requirements

- Android 8.0 (API 26) or newer. Built against API 36.
- Overlay, notification access and accessibility permissions are requested on first launch. Bluetooth permission is requested for Bluetooth alerts.
- Shizuku is optional and unlocks extra controls.

### Known issues

- The welcome dialog still links to the upstream Telegram community.
- Many descriptive strings still call the feature "Smart Island".
- New Layout group titles have no translations yet and fall back to English.
- Not yet checked on a device: Layout and home header at the largest font size, in landscape and with TalkBack.
- Planned (open issues): symbols-only pill ([#10](https://github.com/niteeshbharadwaj2002/NotchIQ/issues/10)), camera and microphone indicator dots ([#11](https://github.com/niteeshbharadwaj2002/NotchIQ/issues/11)), tap to open a control center ([#12](https://github.com/niteeshbharadwaj2002/NotchIQ/issues/12)), swipe down for the notification center ([#13](https://github.com/niteeshbharadwaj2002/NotchIQ/issues/13)).
